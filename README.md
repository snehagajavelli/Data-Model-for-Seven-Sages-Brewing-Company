# 🍺 Seven Sages Brewing Company | Power BI Project

## 📌 Project Overview

I built an end-to-end Power BI solution for **Seven Sages Brewing Company (SSBC)**, transforming data from multiple sources into a centralized and structured data model.

The goal of this project was to help the CFO analyze **beer sales, costs, and profitability** and identify which products perform best.

---

## 🎯 Project Objective

The main objectives were to:

- Combine data from multiple source files
- Clean and transform the data
- Build a structured Power BI data model
- Analyze sales and profitability
- Create financial KPIs using DAX
- Support financial analysis in two currencies
- Build an interactive dashboard for decision-making

---

## 🛠️ Tools & Technologies

- **Power BI Desktop**
- **Power Query**
- **DAX**
- **Data Modeling**
- **Data Visualization**
- **Time Intelligence**

---

## 🔄 Project Workflow

### 1. Data Collection
I reviewed the available source files and understood the structure and purpose of each dataset.

### 2. Data Transformation
Using **Power Query**, I cleaned, formatted, transformed, and combined the source data before loading it into the data model.

### 3. Data Modeling
I designed the data model by organizing the data into fact and dimension tables and creating the required relationships.

### 4. Date Table
I created a dedicated **Date table** to support time-based analysis and time-intelligence calculations.

### 5. DAX Measures
I developed six financial measures covering:

- Sales
- Cost of Sales
- Gross Profit Margin
- Financial calculations across two currencies

### 6. Report Development
Finally, I developed interactive Power BI report pages to make it easier to explore sales performance and profitability.

---

## 📊 Key Insights

The final report enables users to:

- Analyze beer sales performance
- Compare product profitability
- Monitor financial KPIs
- Analyze results across two currencies
- Identify higher-performing products
- Make data-driven business decisions
